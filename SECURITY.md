# 🔒 Security Policy

Thank you for helping keep NEXUS secure.

## Supported Versions

| Version | Supported |
|---|---|
| 0.4.0 | ✅ |
| Older versions | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability in NEXUS, please report it responsibly.

Do not publish sensitive vulnerability details in public Issues.

You can contact the project maintainer through GitHub:

https://github.com/ivankaban723-ship-it

## Please Include

- Description of the vulnerability.
- Steps to reproduce.
- Potential security impact.
- Affected version.
- Suggested solution (if available).

## Security Updates

Security fixes and improvements will be included in future releases.

Thank you for helping protect NEXUS!
