## 🧬 ABOUT

**NEXUS** is an independent C++ development project created to provide a convenient environment for writing, compiling and executing C++ programs.

The project focuses on combining essential development tools into one organized workflow.

NEXUS aims to make C++ development more accessible, efficient and convenient.

## ⚡ FEATURES

- **C++ Compilation** — compile C++ source code.
- **Code Execution** — execute compiled programs.
- **Interactive Console** — interact with running programs.
- **Development Workflow** — organize coding, compiling and execution.
- **Linux Support** — designed for Linux environments.
- **Modular Development** — designed with future expansion in mind.

## 📦 INSTALLATION

### Requirements

- Linux
- Python 3
- GCC / G++
- Git
- pip

### 1. Clone the repository

```bash
git clone https://github.com/ivankaban723-ship-it/NEXUS.git
```

### 2. Enter the project directory

```bash
cd NEXUS
```

### 3. Open the project

```bash
cd NEXUS_0.4.0
```

### 4. Install dependencies

If the release contains a requirements.txt file:

```bash
pip install -r requirements.txt
```

### 5. Start NEXUS

```bash
chmod +x run.sh
./run.sh
```
