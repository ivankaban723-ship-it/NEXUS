## 🧬 About NEXUS

**NEXUS** is a C++ development project designed to provide a convenient and powerful workflow for developers.

The project combines code management, compilation and execution into one environment.

## ⚡ Features

- C++ code compilation
- Program execution
- Integrated console
- Interactive user input
- Organized project architecture
- Linux compatibility
- Lightweight and modular structure

## 🚀 Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
cd NEXUS
```

Give execution permissions:

```bash
chmod +x run.sh
```

Launch:

```bash
./run.sh
```
